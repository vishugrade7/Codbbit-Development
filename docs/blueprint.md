# **App Name**: Salesforce Coder

## Core Features:

- Code Execution: Execute code with a Salesforce connected app, providing real-time feedback and error handling.
- Question Database: Store and manage coding questions and their metadata in Firestore.
- User Management: Store and manage user details, progress, and preferences in Firestore.
- Salesforce API Integration: Connect to Salesforce using a connected app to authenticate and execute code within the Salesforce environment.
- Code Completion Suggestions: Use generative AI to provide code completion suggestions while the user types to help them find Salesforce API methods or objects faster.

## Style Guidelines:

- Primary color: Dark blue (#2C3E50) for a professional and serious tone, reminiscent of Salesforce's branding.
- Background color: Light gray (#F0F4F8) for a clean and modern look.
- Accent color: Teal (#008080) to highlight interactive elements and calls to action.
- Headlines: 'Space Grotesk', sans-serif for a modern and slightly techy feel.
- Body text: 'Inter', sans-serif for readability and a clean appearance.
- Code font: 'Source Code Pro' for clear presentation of code snippets and execution results.
- Use clear and professional icons from Lucide to represent different code functions and actions.
